IN EINFACHEN WORTEN
IN PLAIN WORDS

Dateien bleiben Dateien. Der Platzbedarf sinkt.

The same files. A smaller footprint.

Wer den Rest dieser Seite bewerten will, braucht zuerst eine Antwort auf die einfachste Frage: Wofür ist das gut? Drei Absätze genügen.

Before judging the rest of this page, you need an answer to the simplest question: what is this good for? Three paragraphs are enough.

DAS PROBLEMTHE PROBLEM Dieselben Daten liegen immer wieder auf der Platte The same data sits on disk again and again

Backups, Snapshots, VM-Images und Software-Stände speichern zum großen Teil identische Inhalte. Jede weitere Vollsicherung belegt erneut vollen Platz, obwohl sich zwischen zwei Ständen oft nur wenige Prozent ändern. Der Kapazitätsbedarf wächst mit der Aufbewahrungsdauer, nicht mit der tatsächlichen Datenmenge.

Backups, snapshots, VM images, and software builds largely store identical content. Every additional full backup takes up the full space again, even though only a few percent typically change between two states. Capacity grows with retention, not with the amount of actual data.

DIE IDEETHE IDEA Vorhandene Inhalte wiederverwenden Reuse content already stored

fastdup zerlegt jede Datei beim Schreiben in Blöcke und berechnet für jeden Block einen Fingerabdruck. Ist ein Block bereits vorhanden, wird er nicht erneut geschrieben, sondern nur referenziert. Was danach übrig bleibt, wird komprimiert. Dieses Verfahren heißt Deduplizierung und läuft im Schreibpfad, nicht als nachgelagerter Aufräumjob.

On write, fastdup splits every file into blocks and computes a fingerprint for each one. If a block already exists, it is referenced instead of written again. Whatever remains is then compressed. This is called deduplication, and it happens in the write path rather than as a later cleanup job.

FÜR ANWENDUNGENFOR APPLICATIONS Von außen ein ganz normales Dateisystem From the outside, an ordinary filesystem

Backup-Software, Skripte und Nutzer sehen Ordner und Dateien — über eine SMB-Freigabe im Netz oder einen lokalen Mountpoint auf der Appliance. Von der Deduplizierung merken sie nichts. Verwaltet wird alles im Browser: Datenträger auswählen, Freigaben anlegen, Auslastung beobachten, warten.

Backup software, scripts, and users see folders and files — over an SMB share on the network or a local mountpoint on the appliance. They notice nothing of the deduplication. Everything is managed in the browser: select drives, create shares, watch utilization, run maintenance.

Jede Stufe spart dort, wo sie hilft.

Each stage saves where it can.

Die Standard-Pipeline arbeitet beim Schreiben. Online-Similarity lässt sich gezielt für passende Freigaben zuschalten.

The default pipeline runs on write. Enable online similarity for shares whose data benefits from it.

DEFAULT

SeqCDC + BLAKE3

Inhaltsabhängige Chunk-Grenzen erkennen wiederkehrende Bereiche auch nach Verschiebungen. Exact Dedup verwendet verifizierte vorhandene Inhalte erneut.

Content-defined chunk boundaries recognize repeated regions even after shifts. Exact Dedup reuses verified existing content.

DEFAULT

HOLE / FILL + Zstd

Leere und konstante Bereiche werden kompakt beschrieben. Neue Inhalte werden gruppiert komprimiert, wenn die definierte Sparschwelle erreicht wird; sonst bleibt RAW.

Sparse and constant regions use compact descriptions. New content is compressed in groups when it meets the savings threshold; otherwise it stays RAW.

OPT-IN

Online-Similarity

Neue unabhängige Chunks werden ohne Remount oder Offline-Rebuild als Kandidaten aufgenommen. Der permanente Index bleibt neu aufbaubare Beschleunigung.

New independent chunks become candidates without a remount or offline rebuild. The persistent index remains rebuildable acceleration.

OPT-IN

BUILT WITH RUST

Speichersicherheit beginnt bei der Sprache.

Memory safety starts with the language.

Storage-Kern und Management-Dienste sind in Rust geschrieben. Safe Rust verhindert ganze Klassen von Speicherfehlern, etwa Zugriffe auf bereits freigegebenen Speicher. So adressieren wir eine wesentliche Ursache von Sicherheitslücken in C/C++-Systemen.

The storage core and management services are written in Rust. Safe Rust prevents classes of memory errors, such as accessing freed memory, addressing a major source of vulnerabilities in C/C++ systems.

Deduplizierung
Deduplication
Gleiche Dateninhalte werden nur einmal physisch gespeichert; jedes weitere Vorkommen ist ein Verweis.
Identical content is physically stored once; every further occurrence is a reference.
Chunk / Chunking (CDC)
Chunk / chunking (CDC)
Die Zerlegung einer Datei in Blöcke. Bei Content-Defined Chunking richten sich die Grenzen nach dem Inhalt, damit Einfügungen nicht alles Folgende verschieben.
Splitting a file into blocks. With content-defined chunking the boundaries follow the content, so an insertion does not shift everything after it.
BLAKE3
BLAKE3
Das Prüfsummenverfahren, das jedem Block seinen Fingerabdruck gibt — schnell und für den Wiedererkennungs-Vergleich geeignet.
The checksum function that gives each block its fingerprint — fast and suited to the recognition lookup.
Zstd
Zstd
Ein Kompressionsverfahren, das auf das übrig gebliebene, nicht deduplizierte Datenmaterial angewendet wird.
A compression algorithm applied to the remaining, non-deduplicated data.

Metadata tier and DATA tier
Zwei getrennte Datenträger: der eine hält Verzeichnisse, Manifeste und Indizes, der andere die eigentlichen Datenblöcke.
Two separate drives: one holds directories, manifests, and indexes, the other the actual data blocks.

FUSE

The Linux interface through which fastdup mounts as an ordinary filesystem without being a kernel module.

SMB / Samba

The network file-sharing protocol Windows clients and backup software use to reach the appliance.
Scrub
Scrub

GC (garbage collection)
Das Freiräumen von Blöcken, auf die keine Datei mehr verweist — nötig, weil gelöschte Dateien nicht sofort Platz freigeben.
Reclaiming blocks no file references any more — needed because deleting a file does not immediately free space.
Fast Clone
Fast Clone
Eine Kopie innerhalb der Appliance, die nur Metadaten anlegt und auf vorhandene Daten verweist, statt sie erneut zu schreiben.
A copy inside the appliance that only creates metadata and points at existing data instead of writing it again.
WORM
WORM
Write Once Read Many: Daten sind nach dem Schreiben für eine festgelegte Frist unveränderbar. fastdup bietet das nicht.
Write once, read many: data cannot be altered for a defined period after writing. fastdup does not offer this.
Logische Quota
Logical quota
Eine Obergrenze auf die Nutzdatenmenge einer Freigabe — nicht auf den nach Reduktion tatsächlich belegten Platz.
A ceiling on a share's logical data volume — not on the space actually occupied after reduction.
MiB/s und Peak RSS
MiB/s and peak RSS
Durchsatz in Mebibyte pro Sekunde (1 MiB = 1.048.576 Byte) und der höchste Arbeitsspeicherbedarf eines Prozesses während eines Laufs.
Throughput in mebibytes per second (1 MiB = 1,048,576 bytes) and the highest memory a process used during a run.
Control Plane
Control plane
Der lokale Verwaltungsdienst, der die WebUI ausliefert und Aktionen wie Provisionieren, Mounten oder Warten ausführt.
The local management service that serves the WebUI and carries out actions such as provisioning, mounting, and maintenance.
