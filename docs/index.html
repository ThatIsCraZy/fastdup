IN PLAIN WORDS

Was fastdup macht — ohne Fachbegriffe.

What fastdup does — without the jargon.

Wer den Rest dieser Seite bewerten will, braucht zuerst eine Antwort auf die einfachste Frage: Wofür ist das gut? Drei Absätze genügen.

Before judging the rest of this page, you need an answer to the simplest question: what is this good for? Three paragraphs are enough.

DAS PROBLEMTHE PROBLEM Dieselben Daten liegen immer wieder auf der Platte The same data sits on disk again and again

Backups, Snapshots, VM-Images und Software-Stände speichern zum großen Teil identische Inhalte. Jede weitere Vollsicherung belegt erneut vollen Platz, obwohl sich zwischen zwei Ständen oft nur wenige Prozent ändern. Der Kapazitätsbedarf wächst mit der Aufbewahrungsdauer, nicht mit der tatsächlichen Datenmenge.

Backups, snapshots, VM images, and software builds largely store identical content. Every additional full backup takes up the full space again, even though only a few percent typically change between two states. Capacity grows with retention, not with the amount of actual data.

DIE IDEETHE IDEA Jeder Block wird nur einmal gespeichert Each block is stored only once

fastdup zerlegt jede Datei beim Schreiben in Blöcke und berechnet für jeden Block einen Fingerabdruck. Ist ein Block bereits vorhanden, wird er nicht erneut geschrieben, sondern nur referenziert. Was danach übrig bleibt, wird komprimiert. Dieses Verfahren heißt Deduplizierung und läuft im Schreibpfad, nicht als nachgelagerter Aufräumjob.

On write, fastdup splits every file into blocks and computes a fingerprint for each one. If a block already exists, it is referenced instead of written again. Whatever remains is then compressed. This is called deduplication, and it happens in the write path rather than as a later cleanup job.

FÜR ANWENDUNGENFOR APPLICATIONS Von außen ein ganz normales Dateisystem From the outside, an ordinary filesystem

Backup-Software, Skripte und Nutzer sehen Ordner und Dateien — über eine SMB-Freigabe im Netz oder einen lokalen Mountpoint auf der Appliance. Von der Deduplizierung merken sie nichts. Verwaltet wird alles im Browser: Datenträger auswählen, Freigaben anlegen, Auslastung beobachten, warten.

Backup software, scripts, and users see folders and files — over an SMB share on the network or a local mountpoint on the appliance. They notice nothing of the deduplication. Everything is managed in the browser: select drives, create shares, watch utilization, run maintenance.

EIN BEISPIEL AUS DEM MESSLAUFAN EXAMPLE FROM THE TEST RUN

50 ISO-Versionen mit jeweils kleinen Änderungen ergeben 103,62 GB Nutzdaten. Auf dem Datenträger belegen sie 2,11 GB plus 99,27 MB Metadaten. Anders gesagt: Alle 50 Versionen zusammen brauchen deutlich weniger Platz als eine einzige davon.

50 ISO versions, each with small changes, add up to 103.62 GB of logical data. On disk they occupy 2.11 GB plus 99.27 MB of metadata. Put differently: all 50 versions together need considerably less space than a single one of them.

Wie stark ein Datenbestand schrumpft, hängt davon ab, wie viel sich zwischen den Ständen wiederholt. Einmalige, bereits komprimierte oder verschlüsselte Daten reduzieren sich kaum — dort bleibt vor allem die Kompression.

How much a data set shrinks depends on how much repeats between states. One-off, already compressed, or encrypted data barely reduces at all — there, compression is what remains.

fastdup is not tied to a fixed appliance chassis. Install Rocky Linux 10 on a suitable x86-64 system, provide a fast metadata tier and a separate DATA tier, and turn the machine into FUSE/SMB storage with transparent data reduction by installing one RPM.

MEASURED, NOT PROJECTED

Hoher Durchsatz auf einer kleinen Notebook-CPU-VM.

High throughput on a small notebook-CPU VM.

Der Messhost war keine große Storage-CPU: eine VM auf einem Intel Core i7-1370P aus der Notebook-Klasse, mit nur zehn sichtbaren logischen CPUs, AVX2/BMI2 und ohne AVX-512. Der aktuelle SMB-Lauf blieb dabei bei 569,5 MB Peak RSS und 0 Byte Prozess-Swap.

The measured host was not a large storage CPU: a VM on a notebook-class Intel Core i7-1370P, exposing only ten logical CPUs, with AVX2/BMI2 and no AVX-512. The current SMB run stayed at 569.5 MB peak RSS and zero bytes of process swap.

Drei Kopien testen nicht das maximale Reduction-Potenzial. Three copies do not test the maximum reduction potential.

Bei drei identischen Kopien kann reine Exact-Dedup höchstens 66,67 % einsparen. fastdup erreicht im dauerhaften SMB-Lauf 67,78 % inklusive Metadaten—dank zusätzlicher Reduction-Stufen sogar etwas mehr als dieses reine Dedup-Limit. Im aktuellen Live-Test mit 50 minimal veränderten ISO-Versionen steigt das Verhältnis auf 49,07× für DATA beziehungsweise 46,87× inklusive sämtlicher Metadaten.

With three identical copies, exact dedup alone can save at most 66.67%. fastdup reaches 67.78% in the durable SMB run including metadata—additional reduction stages push it slightly beyond that dedup-only limit. In the current live test with 50 minimally changed ISO versions, the ratio rises to 49.07× for DATA and 46.87× including all metadata.

MULTI-STAGE DATA REDUCTION

Mehr als die klassische Exact-Dedup-plus-Kompression-Pipeline.

Beyond the classic exact-dedup-plus-compression pipeline.

Reduction heißt hier schlicht: weniger belegter Platz für dieselben Daten. fastdup verbindet dafür mehrere unabhängige Stufen, die beim Schreiben nacheinander greifen, und veröffentlicht ihre Grenzen, Entscheidungen und Formate. Welche internen Verfahren proprietäre Legacy-Appliances kombinieren, ist nicht vollständig offengelegt und deshalb nicht seriös zählbar—vergleichbar ist hier die offen dokumentierte Pipeline.

Reduction simply means less space used for the same data. fastdup combines several independent stages that apply one after another on write, and publishes their boundaries, decisions, and formats. Proprietary legacy appliances do not fully disclose every internal technique, so a numeric technique count would not be defensible—the meaningful difference is this openly documented pipeline.

AKTIVACTIVE

SeqCDC-v1

Content-Defined Chunking findet stabile Grenzen trotz Einfügungen und Verschiebungen.

Content-defined chunking finds stable boundaries across insertions and shifts.

Im Klartext: Die Blockgrenzen richten sich nach dem Inhalt. Wird am Anfang einer Datei etwas eingefügt, verschieben sich nicht alle folgenden Blöcke — der Rest wird weiterhin wiedererkannt.

In plain words: Block boundaries follow the content. If something is inserted at the start of a file, the following blocks do not all shift — the rest is still recognized.

AKTIVACTIVE

BLAKE3 Exact Dedup

Identische Chunks werden bytegenau geprüft und nur einmal physisch referenziert.

Identical chunks are byte-verified and physically referenced only once.

Im Klartext: Jeder Block bekommt einen Fingerabdruck. Bei einem Treffer wird zusätzlich Byte für Byte verglichen, bevor auf den vorhandenen Block verwiesen wird.

In plain words: Every block gets a fingerprint. On a match the bytes are compared as well before the existing block is referenced.

AKTIVACTIVE

HOLE + FILL

Sparse Nullbereiche benötigen keinen DATA-Record; konstante Bytebereiche werden als FILL abgebildet.

Sparse zero ranges need no DATA record; constant-byte ranges become FILL extents.

Im Klartext: Leere und durchgängig gleiche Bereiche — etwa vorbelegte Datenbank- oder VM-Dateien — werden notiert statt gespeichert.

In plain words: Empty and uniformly repeating ranges — preallocated database or VM files, for example — are noted instead of stored.

AKTIVACTIVE

Gruppiertes Zstd

Grouped Zstd

Benachbarte Chunks teilen begrenzte Compression Regions; Zstd gewinnt nur oberhalb der versionierten Sparschwelle.

Neighboring chunks share bounded compression regions; Zstd wins only above the versioned saving threshold.

Im Klartext: Was nach dem Deduplizieren übrig bleibt, wird komprimiert — aber nur dort, wo es sich messbar lohnt.

In plain words: Whatever remains after deduplication gets compressed — but only where it measurably pays off.

WORKLOAD

Metadata Fast Clone

copy_file_range klont bereits unveränderliche Extents, ohne DATA erneut zu lesen oder zu speichern.

copy_file_range clones immutable extents without rereading or storing DATA again.

Im Klartext: Eine Kopie innerhalb der Appliance verweist auf vorhandene Daten, statt sie erneut zu lesen und zu schreiben. Wie viel das bringt, hängt davon ab, wie die Anwendung kopiert.

In plain words: A copy made inside the appliance points at existing data instead of reading and writing it again. How much this helps depends on how the application copies.

OPT-IN

Similarity + Depth-1 Codecs

Ein rebuildbarer Similarity Index lässt ZSTD_PREFIX und Sparse-XOR unter derselben begrenzten Sparpolitik gegeneinander antreten. Jede abhängige Kodierung hat genau eine unabhängig dekodierbare Base.

A rebuildable similarity index trials ZSTD_PREFIX and Sparse-XOR under the same bounded saving policy. Every dependent encoding has exactly one independently decodable base.

Im Klartext: Bei ähnlichen Blöcken speichert fastdup entweder nur geänderte Bytes oder komprimiert sie gemeinsam mit einer vorhandenen Basis. Der Pfad ist standardmäßig aus, solange die Messgrundlage über mehrere Workloads noch schmal ist.

In plain words: For similar blocks, fastdup either stores only the changed bytes or compresses them together with an existing base. This path is off by default while the evidence across workloads is still thin.

FaustregelRule of thumb

Wenn der Verlust des Repositories den Betrieb stören würde, gehört mindestens eine weitere, unabhängige Kopie dazu. If losing the repository would disrupt operations, at least one additional independent copy belongs in the picture. Commercial appliances such as Dell PowerProtect Data Domain or HPE StoreOnce bring integrations, retention, cyber resilience, and support that fastdup does not have — and does not claim to have.

  • Kein Schutz vor Geräteverlust, keine Replikation, kein WORM. Fällt ein Datenträger aus, hilft nur Redundanz im Block-Layer darunter — und eine zweite Kopie an einem anderen Ort.
  • No device-loss protection, no replication, no WORM. If a drive fails, only redundancy in the block layer below helps — plus a second copy somewhere else.
  • POSIX-/Samba-Kompatibilität noch unvollständig. Einzelne Anwendungen können sich anders verhalten als auf einem klassischen Dateisystem. Vor dem Einsatz mit der eigenen Software testen.
  • POSIX/Samba compatibility remains incomplete. Individual applications may behave differently than on a classic filesystem. Test with your own software before relying on it.
  • Samba Fast Clone ist experimentell. Als Veeam-Repository ist fastdup derzeit nicht qualifiziert.
  • Samba Fast Clone is experimental. fastdup is currently not qualified as a Veeam repository.
  • Kein Produktions-Support, keine Performance-SLA. Fragen und Fehler laufen über GitHub Issues, nicht über einen Support-Vertrag.
  • No production support, no performance SLA. Questions and bugs go through GitHub issues, not through a support contract.
BEGRIFFE
GLOSSARY

Die Fachbegriffe dieser Seite, je ein Satz.

Every technical term on this page, in one sentence.

Deduplizierung
Deduplication
Gleiche Dateninhalte werden nur einmal physisch gespeichert; jedes weitere Vorkommen ist ein Verweis.
Identical content is physically stored once; every further occurrence is a reference.
Chunk / Chunking (CDC)
Chunk / chunking (CDC)
Die Zerlegung einer Datei in Blöcke. Bei Content-Defined Chunking richten sich die Grenzen nach dem Inhalt, damit Einfügungen nicht alles Folgende verschieben.
Splitting a file into blocks. With content-defined chunking the boundaries follow the content, so an insertion does not shift everything after it.
BLAKE3
BLAKE3
Das Prüfsummenverfahren, das jedem Block seinen Fingerabdruck gibt — schnell und für den Wiedererkennungs-Vergleich geeignet.
The checksum function that gives each block its fingerprint — fast and suited to the recognition lookup.
Zstd
Zstd
Ein Kompressionsverfahren, das auf das übrig gebliebene, nicht deduplizierte Datenmaterial angewendet wird.
A compression algorithm applied to the remaining, non-deduplicated data.
Metadata-Tier und DATA-Tier
Metadata tier and DATA tier
Zwei getrennte Datenträger: der eine hält Verzeichnisse, Manifeste und Indizes, der andere die eigentlichen Datenblöcke.
Two separate drives: one holds directories, manifests, and indexes, the other the actual data blocks.
FUSE
FUSE
Die Linux-Schnittstelle, über die fastdup als normales Dateisystem eingehängt wird, ohne Kernel-Modul zu sein.
The Linux interface through which fastdup mounts as an ordinary filesystem without being a kernel module.
SMB / Samba
SMB / Samba
Das Netzwerkprotokoll für Dateifreigaben, über das Windows-Clients und Backup-Software auf die Appliance zugreifen.
The network file-sharing protocol Windows clients and backup software use to reach the appliance.
Scrub
Scrub
Ein Prüflauf, der gespeicherte Daten gegen ihre Prüfsummen liest und stille Fehler sichtbar macht.
A verification pass that reads stored data against its checksums and surfaces silent corruption.
GC (Garbage Collection)
GC (garbage collection)
Das Freiräumen von Blöcken, auf die keine Datei mehr verweist — nötig, weil gelöschte Dateien nicht sofort Platz freigeben.
Reclaiming blocks no file references any more — needed because deleting a file does not immediately free space.
Fast Clone
Fast Clone
Eine Kopie innerhalb der Appliance, die nur Metadaten anlegt und auf vorhandene Daten verweist, statt sie erneut zu schreiben.
A copy inside the appliance that only creates metadata and points at existing data instead of writing it again.
WORM
WORM
Write Once Read Many: Daten sind nach dem Schreiben für eine festgelegte Frist unveränderbar. fastdup bietet das nicht.
Write once, read many: data cannot be altered for a defined period after writing. fastdup does not offer this.
Logische Quota
Logical quota
Eine Obergrenze auf die Nutzdatenmenge einer Freigabe — nicht auf den nach Reduktion tatsächlich belegten Platz.
A ceiling on a share's logical data volume — not on the space actually occupied after reduction.
MiB/s und Peak RSS
MiB/s and peak RSS
Durchsatz in Mebibyte pro Sekunde (1 MiB = 1.048.576 Byte) und der höchste Arbeitsspeicherbedarf eines Prozesses während eines Laufs.
Throughput in mebibytes per second (1 MiB = 1,048,576 bytes) and the highest memory a process used during a run.
Control Plane
Control plane
Der lokale Verwaltungsdienst, der die WebUI ausliefert und Aktionen wie Provisionieren, Mounten oder Warten ausführt.
The local management service that serves the WebUI and carries out actions such as provisioning, mounting, and maintenance.
