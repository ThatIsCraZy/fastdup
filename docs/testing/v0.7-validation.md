# v0.7 validation — 7 September 2026

The release uses package version 0.7.0-1 and Git tag v0.7. It includes committed
scrub resume from ADR 0092 and the new usage/cache-window telemetry and WebUI.

- 228 Rust library/binary tests: store, POSIX, appliance and control, including
  counter-window rollover/reset tests, historical serialization, worker stop
  and resume, integrity latching and bounded logical-usage sampling.
- Six allocation/sparse tests, including logical usage after sparse writes,
  overwrites, hard links and hole punching.
- 27 structural/startup/scrub-resume integration tests with durable fault injection.
- 56 end-to-end maintenance/GC tests.
- 38 React tests: initialized versus uninitialized drive pages, unavailable
  usage, role assignment, five-minute/lifetime switching and missing windows.
- Binary and source RPM packaging (`0.7.0-1.el10`), RPM digest checks and
  release SHA-256 manifest.
- Production Clippy with warnings denied and TypeScript/Vite build.
- Chromium rendering of storage and cache views, plus a 390-pixel mobile view:
  no page errors or document overflow. Documentation images are illustrative
  fixtures rendered by the real React UI, not live VM measurements.

Total: 355 passing tests. Existing manual benchmark cases remain ignored.
Logs and browser captures are under `.artifacts/v0.7/` in the build workspace.

The logical-allocation sampler reads at most 4096 cached inode counters per
inspection without waiting for catalog/inode writers or reading DATA. A sampled
inode high-water bound prevents concurrent creation from extending one pass
forever. The timestamp identifies a completed pass, not an atomic filesystem
snapshot. Large or busy namespaces may retain an older observation.

The cache window stores counter snapshots in the agent, not the browser. It
keeps at most 301 distinct one-second observations. Window duration may be less
than 300 seconds after startup, missing observations, runtime changes or counter
resets. No interpolation or lifetime fallback manufactures a recent hit rate.
No Veeam throughput measurement or test-VM runtime restart is part of this release.
