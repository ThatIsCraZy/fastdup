# Prove owned publications by the exact writer image

This record required a complete storage reread to equal the retained writer
image before publication. ADR 0056 replaced the reread with sampling, then ADR
0059 replaced storage comparison with exact writer evidence until an independent
read. Use ADRs 0059 and 0060 for the current publication and structural-proof
contract.
